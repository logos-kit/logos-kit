# Security Policy

Logos Kit is a wallet. Please report vulnerabilities privately, and do not open public issues for them.

- Email: blockchainoracle.dev@gmail.com
- Please include: affected component (engine / Basecamp module / npm package / embedded wallet), version or commit, reproduction steps, and impact.

We aim to acknowledge reports within 72 hours. This software targets **testnets** and is unaudited: do not use it with mainnet funds.
