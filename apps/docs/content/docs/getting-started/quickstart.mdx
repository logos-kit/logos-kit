You'll end with a Basecamp app that connects to the wallet, shows the
account's balance, gets test funds in-flow, and sends LEZ with a receipt.

<Shot name="template-receipt" caption="What you'll have: the template after a send, with its receipt." />

You need [Nix](https://nixos.org/download) with flakes, and Basecamp with
Logos Kit Wallet installed ([Installation](/docs/getting-started/installation)).

<Steps>
<Step>

### Start from the template

```sh
mkdir my-app && cd my-app
nix flake init -t github:logos-kit/logos-kit#dapp
```

You get a `ui_qml` module: `metadata.json`, `qml/Main.qml`, the SDK in
`qml/LogosKit/`, the UI kit in `qml/LogosKitUi/`, and the wallet's contract in
`logos_kit_wallet.lidl`.

</Step>
<Step>

### Name it

In `metadata.json`, set `name` (lowercase with `_`), `display_name` and
`description`, and replace `src/icons/icon.png`. Keep every intent you use
under `uses`; they must be objects:

```json
"uses": [
  { "intent": "lez.wallet.connect" },
  { "intent": "lez.transaction.send" },
  { "intent": "lez.wallet.request_funds" }
]
```

</Step>
<Step>

### Build and install

```sh
nix build .#lgx-portable
```

Install `result/*.lgx` from Basecamp's Package Manager ("Install
from file"), or with `lgpm install --file result/*.lgx`. Your app
appears in the sidebar.

</Step>
<Step>

### Connect and send

The template already does this. The core of it:

```qml
import "LogosKit"

LogosKit { id: kit; visible: root.visible }

// The wallet asks the user which account to share.
kit.api.connect({ accountKinds: ["public"] }).then(function (session) {
    root.account = session.accounts[0].address
})

// The user approves in the wallet; you get a handle, then follow it.
kit.api.transfer(root.account, to, "42").then(function (r) {
    kit.api.watchTransaction(r.handle, function (s) {
        console.log(s.lifecycle, s.outcome)   // submitted … included success
    })
})
```

</Step>
</Steps>

<Shot name="wallet-approval" caption="Your proposals appear in the wallet with your app's icon and name, decoded." />

## Develop against a local chain

The SDK follows the wallet's network. Run a local sequencer, switch the wallet
to **LEZ local** (Settings → Network), and your app follows. `kit.chain` tells
you where you are.
