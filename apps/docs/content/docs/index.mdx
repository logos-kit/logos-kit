Logos Kit is two things that ship together:

- **A wallet** for the [Logos Execution Zone](https://logos.co) (LEZ): public and
  private accounts, native LEZ and tokens, private transfers proved on the
  user's own machine, and approvals that show what a transaction really does.
- **An SDK** your app uses to ask that wallet for things: connect, read
  balances, propose transfers and program calls, and follow them until they
  land. It runs in Basecamp apps (QML) and in scripts and web apps
  (TypeScript).

Keys, accounts and approvals live only in the wallet. Your app asks; the user
decides.

## What you get

| | |
|---|---|
| **Private by default** | Public and private accounts side by side. Private transfers are proved locally with RISC Zero: minutes on a laptop, and the app never sees a key. |
| **Approvals you can read** | Every request is decoded into effects (who pays whom, which token, which program), with the fee cap and the program's source verification. Calls the wallet can't read are flagged as such. |
| **Honest outcomes** | LEZ 0.3 includes failed transactions, so "included" isn't "worked". The wallet proves the effect from chain state and reports `success`, `failure` or `unknown`. |
| **Built for Basecamp** | User-facing steps are Basecamp intents, so the shell attests which app is asking. Reads are plain module calls. |
| **One API, two runtimes** | The same calls from QML (`LogosKit`) and TypeScript (`@logos-kit/client`), with byte-exact LEZ encoding (`@logos-kit/codec`). |
| **Apps to copy** | A testimonial app, a faucet app and a template, each with loading, pending, error and unconfirmed states. |

## How the pieces fit

```
┌─────────────┐   intent (connect, send, sign, funds)   ┌──────────────────┐
│  your app   │ ─────────────────────────────────────▶ │  Basecamp shell  │
│ (LogosKit)  │                                         └────────┬─────────┘
│             │                                                  ▼
│             │   module call (reads, status)          ┌──────────────────┐
│             │ ─────────────────────────────────────▶ │  Logos Kit wallet│
└─────────────┘                                         │  keys · approvals│
                                                        │  proving · policy│
                                                        └────────┬─────────┘
                                                                 ▼
                                                     LEZ sequencer (zone)
```

| Piece | Where |
|---|---|
| Wallet (Basecamp) | `logos_kit_wallet_ui` over the core module `logos_kit_wallet`, from the [Logos Kit catalog](/docs/wallet/install) |
| Wallet (terminal) | [`logos-kit` CLI](/docs/wallet/cli), same engine and policy |
| QML SDK and UI kit | `sdk/qml/LogosKit/`, `sdk/qml/LogosKitUi/` ([QML SDK](/docs/sdk/qml)) |
| TypeScript SDK | `@logos-kit/client`, `@logos-kit/codec` ([client](/docs/sdk/client)) |
| Protocol | LWS-0: [methods](/docs/reference/methods) and [intents](/docs/reference/intents) |

<Callout type="warn" title="Testnets only">
Logos Kit runs on LEZ testnets and is unaudited. Don't use it with anything of
value. Today the wallet defaults to the Logos Kit [preview network](/docs/concepts/networks),
because the official testnet still runs LEZ 0.2.
</Callout>
