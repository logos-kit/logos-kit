Overall direction

In Basecamp, at desktop width

The same wallet inside the real Basecamp shell (sidebar and tabs drawn to match the running app). At 1024 px and up, accounts move to a side list. Switch direction to compare.

Built in Qt Quick, not a web viewEverything above maps to stock QML: Rectangle radii and borders, MultiEffect for shadows and backdrop blur, Behavior animations for the press bounce, Shape for the proving ring.
Our own font ships inside the moduleNunito, Geist or Figtree loads via FontLoader from the module folder, which the sandbox allows. We don't depend on the host font.
Checked in Basecamp on S0Bundled SVG logos render and Canvas paints (probe run 2026-09-26). Remote images are blocked, so every token and brand logo is bundled.
One spec, three renderersThe picked direction becomes @logos-kit/theme tokens that feed QML (Tokens.qml), React (CSS variables) and React Native from one source.
